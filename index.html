AI Vision Pan-Tilt Tracker

Designed and built a Raspberry Pi-based computer vision system capable of detecting and autonomously tracking a face in real time using a servo-driven pan-tilt mechanism.

Integrated a Raspberry Pi 5, Camera Module 3, PCA9685 PWM controller, OpenCV, Python, and servo control into a complete electromechanical tracking system.

Recorded tracking performance during testing and analyzed pan and tilt response data to evaluate the behavior of the control system.

Technologies: Raspberry Pi, Python, OpenCV, Computer Vision, Servo Control, I²C, Embedded Systems, Data Analysis
